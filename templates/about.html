1. Relational Database Design with Django ORM

The system models university courses, student credentials, and course enrollments with foreign keys, unique composite indexes, and database-level check constraints.

Django Models:

  • StudentProfile: Links to Django's built-in User model via OneToOneField, managing role authorization (student vs administrator).
  • Course: Defines course details, instructor, capacity, and available seats, guarded by a model CheckConstraint(Q(available_seats__gte=0) & Q(available_seats__lte=F('max_seats'))).
  • Enrollment: Junction model with composite unique constraint unique_together = ('student', 'course') ensuring duplicate active registrations are impossible.

2. Concurrency & Transaction Safety

Using Django's transaction.atomic() and select_for_update(), seat allocation and cancellation execute as ACID transactions. If two students request the last available seat simultaneously, the database serializes requests to guarantee zero over-subscription.
